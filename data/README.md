# Dataset card: synthetic-stat-metadata-v1

이 데이터는 AI가 작성한 검색 파이프라인 점검용 합성 예제입니다.
실제 통계값, KOSIS 표 ID, 공식 정의의 인용, 독립 검수 결과를 포함하지 않습니다.
통계 정의는 검색 구분을 위해 단순화한 설명이며 공식 정의를 대신하지 않습니다.

## 범위

10개 주제 × 4개 문서 = 40개 문서.
각 주제에서 서울 2024 / 서울 2023 / 부산 2024 / 비슷하지만 다른 지표를 둡니다.
질문은 주제별 3개(정확 표현, 의역, 연도 비교) 및 범위 밖 질문 4개로 총 34개입니다.

- dev: 실업률·고용률·주민등록인구·1인가구 (12+2)
- test: 출산율·고령인구·물가·주택·소득·이동 (18+2)
- 양 split은 질문 주제가 겹치지 않지만 문서 corpus를 공유합니다.
- 템플릿과 작성자가 같으므로 독립적인 외부 평가셋이 아닙니다.
- 정답은 주제·지역·연도 조합으로 부여. 연도 비교 질문은 정답 2개.
- answerable=false는 요청 범위의 자료가 corpus에 없다는 뜻입니다.
- source_url=null은 실자료 출처가 없다는 명시적 표시입니다.

## 실데이터로 교체하기

corpus.jsonl: id, text 필수. 출처 URL, 표 ID, 수집일, 원문 해시, 배포 조건을 추가하세요.
queries.jsonl: id, text, split, topic, category, answerable, relevant_ids 필수.
정답 문서 ID는 corpus에 있어야 하며 같은 질문을 dev/test에 중복하지 않습니다.

실제 지표는 정의·단위·연령 범위·지역·집계 기간이 맞는지 검토해야 합니다.
AI 초안과 사람 검수를 구분하고 검수자/검수일/판정 근거를 기록하세요.
공개 가능한 자료만 넣고 민감 정보와 API 키는 포함하지 마세요.
