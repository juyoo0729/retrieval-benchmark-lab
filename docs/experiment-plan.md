## v0.2: 변경 하나의 효과
dev에서 실패 유형을 읽고 토큰화 또는 모델 하나만 변경합니다.
동일 corpus/query 해시, 동일 k, 동일 하드웨어, 동일 후보 수로 비교합니다.
실패 사례 5개를 고르고 원인과 바뀐 순위를 기록합니다.
실패가 5개보다 적으면 있는 만큼만 기록하고 나머지를 만들어내지 않습니다.
같은 설정을 반복 실행해 시간 변동을 기록합니다.
